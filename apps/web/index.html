How it works

Three steps, no accounts, no cloud.

Everything runs on your own network. The laptops talk only to each other, over encrypted connections.

1

Download and set up

Unzip on every laptop and run Setup.cmd. It installs Python for Daneion (internet needed once) and checks the laptop.

2

Start one controller

On one laptop run Start Controller.cmd. The dashboard opens and shows a one-time pairing code.

3

Join the others

On the other laptops run Join Cluster.cmd and paste the line from the dashboard. Then start a job.

What it is

Honest about what it does.

Daneion speeds up jobs that split into independent pieces. It does not merge laptops into one big machine.

Daneion is

  • Built-in jobs that split into independent tasks
  • 1 to 5 laptops that you own or trust, on one network
  • Results checked by SHA-256 before they count
  • Pairing with one-time codes over pinned, encrypted TLS
  • Owners can pause or remove their laptop at any time

Daneion is not

  • A virtual GPU or pooled RAM / VRAM
  • A way to raise game frame rates
  • A runner for arbitrary code from other people
  • A cloud service: nothing leaves your network
  • Guaranteed faster: FitCheck says when it is not
Help

Before you start

Most problems come from the network, not from Daneion.

Which network should I use?

A phone hotspot or your own router works best. Campus and guest Wi-Fi often block laptops from reaching each other.

Other laptops can't connect to the controller

Windows blocks incoming connections on networks marked Public. On the controller laptop double-click Allow Workers (firewall).cmd in the Daneion folder once. It asks for administrator rights, opens port 8751 and offers to mark the Wi-Fi as Private. For the manual steps run:

uv run daneion firewall
Windows shows a security warning when I run the scripts

The scripts are not code-signed yet, so Windows warns about files from the internet. Check the SHA-256 above first, then choose Run (or More info → Run anyway). To check the hash in PowerShell:

Get-FileHash .\Daneion-0.1.1-windows.zip
Something else is wrong

Run the built-in self-test in the Daneion folder. It checks Python, the network profile, ports, the firewall and the link to the controller:

uv run daneion doctor
What about Linux and macOS?

The code is written to be portable, but only Windows has been tested so far, so only a Windows download is offered.
